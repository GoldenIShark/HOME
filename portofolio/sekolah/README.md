# SMA Cakrawala Nusa

Demo website sekolah modern untuk portofolio Shark Studio.

## Catatan

- Seluruh data sekolah, jadwal, nama, kontak, prestasi, dan PPDB adalah data demo.
- Halaman dibuat dengan HTML, CSS, dan vanilla JavaScript tanpa backend.
- Gambar konten menggunakan URL gambar Unsplash untuk kebutuhan demo dan dimuat lazy di luar hero.
- Tombol pendaftaran hanya menampilkan notifikasi bahwa formulir PPDB adalah fitur demo.
