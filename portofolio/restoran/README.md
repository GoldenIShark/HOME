# Ruang Rasa — Demo Portfolio Shark Studio

Demo website restoran/toko makanan modern untuk menunjukkan kemampuan frontend Shark Studio.

## Teknologi

- HTML semantik
- CSS dengan custom properties dan responsive layout
- JavaScript vanilla tanpa framework atau backend
- Gambar WebP dan lazy loading

## Fitur utama

- Loading screen ringan
- Navigasi mobile dengan hamburger menu
- Hero cinematic dengan animasi halus
- Filter kategori menu
- Scroll reveal berbasis IntersectionObserver
- Gallery lightbox dengan dukungan tombol Escape
- Placeholder lokasi dan jam buka
- Tombol kontak WhatsApp dan Instagram demo

## Struktur

```text
restoran/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    │   ├── hero.webp
    │   ├── food-1.webp
    │   ├── food-2.webp
    │   ├── food-3.webp
    │   └── gallery/
    └── icons/
```

Semua nama restoran, alamat, kontak, dan gambar di proyek ini adalah data demo. Proyek ini tidak memiliki backend, database, login, API, atau sistem admin.
